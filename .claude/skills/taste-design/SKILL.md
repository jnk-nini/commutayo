description: Minimalist, tactile mobile-first UX guidelines for transit interfaces.

- Never build flat, unstyled tables for commuter steps; use vertical dashed landmark timelines[cite: 1].
- Provide immediate visual confirmation chips for fare amounts and time estimates.
- Use clear icon cues (Bus, Car for UV, Footprints for Walk, MapPin for Landmarks)[cite: 1].
